# Gorecraft Demo

Playable Windows demo of **Gorecraft**, wounds, blood, dismemberment and slicing for skeletal meshes in Unreal Engine,
in C++ and replicated. It is the plugin's own example map, a firing range with six stations and eight weapons,
packaged as a Shipping build with UE 5.8. Contains graphic violence and blood.

**Download:** [GorecraftDemo_Win64.zip](https://github.com/filipetessaro/gorecraft-demo/releases/latest/download/GorecraftDemo_Win64.zip)
(221 MB). No engine needed: unzip and run `Gorecraft.exe`.

Fly with WASD and the mouse, pick a weapon with 1 to 8, use it with the left button. N turns the Niagara blood on, R
puts everyone back. The stations and controls are in `HOW_TO_PLAY.txt`, next to the game.

Docs: https://apps.tessaroapps.com/gorecraft/docs/
